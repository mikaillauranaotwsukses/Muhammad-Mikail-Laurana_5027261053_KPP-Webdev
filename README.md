# Mikail - Personal Portfolio

Landing page portofolio pribadi untuk menampilkan profil, keahlian, pengalaman, proyek, dan sertifikat. Dibuat dengan HTML, CSS, dan sedikit JavaScript vanilla tanpa framework apa pun, sehingga ringan, cepat, dan mudah dibuka di mana saja.

## Fitur

- Navbar dengan pilihan posisi atas atau samping
- Hero berisi nama, peran, deskripsi singkat, dan tombol CTA
- Section About: keahlian, pengalaman, pendidikan, dan penghargaan
- Section Projects: 7 proyek dengan tampilan berganti mengikuti scroll
- Section Certificates: galeri 17 sertifikat dengan pratinjau gambar
- Footer berisi kontak dan media sosial
- Tampilan responsif untuk laptop dan ponsel

## Struktur File

```
.
├── index.html
├── style.css
└── assets/
    └── image/
        ├── projects/       7 gambar proyek
        ├── certificates/   17 gambar sertifikat
        └── ...             foto profil dan gambar pendukung
```

## Cara Menjalankan

Buka file `index.html` langsung di browser. Tidak perlu instalasi atau server apa pun.

## Teknologi

- HTML5 dengan tag semantik
- CSS3 (Flexbox, Grid, animasi, media query)
- JavaScript vanilla untuk interaksi scroll dan galeri
- Google Fonts (Inter)
- Font Awesome untuk ikon
